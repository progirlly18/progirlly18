## 🚀 Featured Projects

### 🏥 Hospital Readmission Analytics

An end-to-end **data engineering and analytics pipeline** for
understanding and predicting hospital readmissions using the UCI
Diabetes Readmission dataset.

**Tech:** Python • Pandas • PostgreSQL • Apache Airflow • Streamlit •
Plotly

**Pipeline:**

`Dataset → Ingestion → Cleaning → Feature Engineering → Validation → PostgreSQL → Dashboard`

Key work includes patient/admission data modeling, feature engineering,
ETL orchestration with Airflow, PostgreSQL analytics tables, and an
interactive Streamlit dashboard.

------------------------------------------------------------------------

### 🎙️ AI-Powered Multimodal Interview Assessment System

An AI-based system designed to assess interview performance using
multiple modalities.

**Tech:** Python • Whisper • MiniLM • NLP • Speech Analysis • Computer
Vision

The system explores signals such as **speech, semantic relevance,
emotion and eye contact** to provide structured interview assessment.

------------------------------------------------------------------------

### 💳 Credit Card Fraud Detection

A machine learning project for identifying fraudulent credit-card
transactions on a highly imbalanced dataset.

**Tech:** Python • Scikit-learn • XGBoost • Random Forest • SMOTE •
Jupyter Notebook

The project compares multiple classification approaches while addressing
**class imbalance and data leakage**.

------------------------------------------------------------------------

### 🌿 Green Coding Analyzer

A machine-learning-oriented project focused on estimating the **energy
consumption and carbon footprint of software processes** using factors
such as hardware specifications, execution time and code complexity.

**Tech:** Python • Machine Learning • Jupyter Notebook

------------------------------------------------------------------------

### 🧾 Smart Bill Reader

An AI-powered expense automation platform for digitizing invoices and
extracting useful information automatically.

**Tech:** React Native • Python Flask • Google Cloud Document AI •
Firebase • Google Sheets
